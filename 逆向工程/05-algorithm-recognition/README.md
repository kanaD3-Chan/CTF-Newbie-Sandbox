# 05 - 这是什么加密

程序对输入做了一种看起来很"规整"的变换，然后跟硬编码值比较。

如果你见过某种经典的分组加密算法——Feistel 网络、固定的 delta 常数、多轮迭代——你会觉得眼熟。这道题就是让你认出来它。

## 算法特征

```
delta = 0x9e3779b9
循环 32 轮
每轮把数据分成两半，互相做移位和加法运算
```

> 这基本就是 TEA（Tiny Encryption Algorithm）的翻版。改了几个常数，但骨架没动。

## 怎么解

两种思路：

1. **识别算法**：认出是 TEA，直接写解密函数，把 key 和密文倒过来算一遍
2. **硬逆**：不知道算法名字也没关系——加密过程是对称的，按相反顺序执行相反的运算就行

## Key

```c
uint32_t key[4] = {0xdeadbeef, 0xcafebabe, 0x12345678, 0x87654321};
```

> 这种题考的不是你记不记得 TEA 的实现，而是你能不能从汇编/伪代码里看出"这玩意儿是个标准算法"。以后见到 `0x9e3779b9` 这个数字，条件反射就应该是 Feistel 网络。
