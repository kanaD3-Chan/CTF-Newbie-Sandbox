# 平院网安 CTF 入门学习手册 · 出题库

这里是题目的出题源码，包含 `generate.py` 等出题脚本。源码里可能有 flag，但它不是你该来的地方。

我们相信你会诚实地面对每一道题，而不是跑过来翻源码找答案。

如果你对题目本身有建议、发现了 bug，或者也想贡献一道题，欢迎提 [Issues](https://github.com/kanaD3-Chan/CTF-Newbie-Sandbox/issues) 或者 PR！

---

本仓库是"砺剑护盾"发展型资助育人项目的配套出题库，与[《平院网安 CTF 入门学习手册》](https://kanade-chan.top/ctf-handbook/)配套使用。

每个文件夹对应手册的一个方向，题目按难度递进，供新生在学完对应章节后练手。
